# Web — Fix blank `/courses/$courseId` route (nested-route Outlet bug)

## Goal
Clicking "Open course" on the web rendered a blank page at `/courses/<uuid>`. Restore the course detail page and its sub-routes.

## What Changed
TanStack file-based routing treats `courses.tsx` + `courses.$courseId.tsx` as parent layouts for any `courses.*.tsx` siblings. Both files previously rendered full page content but never an `<Outlet />`, so nested children (`/courses/$courseId`, `/exam`, `/resources`, `/exam/result`) had nowhere to mount and the URL produced an empty screen.

Fix: split each conflicted file into a thin layout (`<Outlet />` only) plus an `.index.tsx` leaf carrying the original page content.

- `courses.tsx` → new pure layout. Original list moved to `courses.index.tsx`.
- `courses.$courseId.tsx` → new pure layout. Original detail moved to `courses.$courseId.index.tsx`.
- `certificates.tsx` → same pattern (was also broken; `certificates.$certificateId` was orphaned).

Route tree (`src/routeTree.gen.ts`) regenerated by Vite/TanStack; now properly wires `CoursesRoute` → `CoursesIndexRoute` + `CoursesCourseIdRoute` → `CoursesCourseIdIndexRoute` + `exam` + `resources`.

## Files Touched
- `guided-journey-lab/src/routes/courses.tsx` (recreated as layout)
- `guided-journey-lab/src/routes/courses.index.tsx` (renamed from `courses.tsx`)
- `guided-journey-lab/src/routes/courses.$courseId.tsx` (recreated as layout)
- `guided-journey-lab/src/routes/courses.$courseId.index.tsx` (renamed from `courses.$courseId.tsx`)
- `guided-journey-lab/src/routes/certificates.tsx` (recreated as layout)

## Risks / Notes
- `/courses/$courseId/exam` and `/courses/$courseId/resources` were also broken before the fix (parent had no Outlet). Now fixed by the same change.
- Pattern to remember: any TanStack route file `foo.tsx` paired with siblings `foo.bar.tsx` must render `<Outlet />`. Use `foo.index.tsx` for the leaf content if `foo.tsx` is acting as layout.
